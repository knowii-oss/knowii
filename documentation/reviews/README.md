# Reviews

Reports of reviews of the whole application. One folder per review, named by its date and its subject.

| Review                                                 | What it holds                                                                                                    |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| [2026-11-17 UI review](2026-11-17-ui-review/report.md) | The UI, design and UX review (#1523): the report, the files of the five reviewers, the index of the screen atlas |

A report is the record of what a review found on one date. It does not change after the review: the issues that it lists hold the work and the decisions.

The pictures of a screen atlas and the output of the accessibility scripts are not in the repository: the tools in `tools/screen-atlas/` make them again from the seed data.
