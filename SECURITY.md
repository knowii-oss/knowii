# Security

How Knowii protects the data of its communities: https://app.knowii.net/security (also `resources/markdown/security.md` in this repository).

## Report a vulnerability

Write to contact@developassion.be with the steps to reproduce the problem. Please do not open a public issue, and give us a reasonable time to fix it before you tell others. We confirm that we received your report and keep you informed.

Do not access, change or delete the data of others while you test, and do not run tests that can degrade the service.
